# Kaito Automotive Group

Egyszerű statikus weboldal, közvetlenül telepíthető Vercelre.

## Fájlok
- `index.html`
- `styles.css`
- `script.js`

## GitHub feltöltés
1. Nyisd meg a `kaito-automotive` repositoryt.
2. Add file → Upload files.
3. Töltsd fel a fenti 3 fájlt.
4. Commit changes.

## Vercel
1. Add New → Project.
2. Importáld a `kaito-automotive` GitHub repositoryt.
3. Framework Preset: Other.
4. Root Directory: maradjon alapértelmezett.
5. Deploy.

A kapcsolat és az árak jelenleg mintaadatok.


## Hero igazítás
A desktop hero HTML-szöveg pozíciója és mérete a jelenlegi borítókép beégetett felirataihoz van igazítva.
